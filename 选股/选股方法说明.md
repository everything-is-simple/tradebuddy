# 选股方法说明：从三本经典到 A 股初选系统

> 依据：Mark Minervini《股票魔法师》Ⅰ/Ⅱ（SEPA）、威廉·欧奈尔《笑傲股市》第4版（CANSLIM）、尼古拉斯·达瓦斯《我如何从股市赚了100万》（箱体理论）
> 配套脚本：`I:\tradebuddy\选股\scan_candidates.py` ｜ 每日清单输出：`I:\tradebuddy\选股\备选清单\`

## 一、三本书其实是同一套思想

| | 达瓦斯（1959） | 欧奈尔（1988/2009） | Minervini（2013） |
|---|---|---|---|
| 核心观点 | 只买**创出新高**的股票 | "看起来太高的股票往往还会更高" | 只在**第二阶段上升趋势**中买入 |
| 买点 | 箱体上沿突破 | 杯柄形态突破点（pivot） | VCP 收缩末端突破 |
| 趋势过滤 | 箱体逐级抬升 | 股价 > 50日/200日线 | 趋势模板八条 |
| 止损 | 跌回箱体即离场 | 买点下方 7-8% | 5-10%，绝不平摊亏损 |
| 精髓 | 强者恒强 + 小亏大赚 | 强者恒强 + 基本面共振 | 强者恒强 + 风险控制至上 |

三本书的例子教程（达瓦斯的钢铁股箱体、欧奈尔的历届美股大牛股复盘、Minervini 的 13000% 实盘案例）讲的都是一件事：**在上升趋势中，等待强势股放量突破新高，错了小亏认错，对了让利润奔跑。**

## 二、把书里的例子翻译成可计算规则

Minervini 趋势模板（原书第2章，Trend Template，共 8 条）中可由行情数据计算的部分，我们做了跨周期翻译：

| 原书条件 | 本系统翻译（A股） | 来源 |
|---|---|---|
| 股价高于 150/200 日线 | 周收盘 > 周MA30（≈150日线） | Minervini 模板 2/3 条 |
| 200日线上升至少 1 个月 | 月收盘 > 月MA10，且月MA10 不向下 | Minervini 模板 4 条 |
| 现价距 52 周高点 ≤ 25% | 输出"距52周高点回撤%"列供人工看 | Minervini 模板 7 条 |
| 欧奈尔"股价创新高"N 条件 | 当日最高价创 20 日新高 | 欧奈尔 CANSLIM 之 N |
| 欧奈尔"突破日大涨放量" | 当日涨幅 > 6% | 欧奈尔对突破日强度的要求 |
| 达瓦斯"箱体逐级抬升" | 周/月线趋势绝对不下跌（均线 filtering） | 达瓦斯箱体理论 |

**设计逻辑：** 涨幅>6% + 20日新高 = 今天有资金把股价顶出了新箱体（达瓦斯买点信号）；月/周线不下跌 = 这个新箱体必须坐落在大级别上升趋势之上（Minervini 第二阶段）。两个条件缺一不可——这正是三本书反复用案例强调的："突破"只有在"趋势正确"的背景下才值得买。

## 三、每日初选条件（硬性，全部满足）

1. **当日涨幅 > 6%**
2. **当日最高价创 20 日新高**（含当日）
3. **周线趋势不在下跌**：周收盘 > 周MA30，且本周周MA30 ≥ 上周周MA30
4. **月线趋势不在下跌**：月收盘 > 月MA10，且本月月MA10 ≥ 上月月MA10
5. 剔除 ST / *ST / 退市股；仅沪深主板、创业板、科创板

参数（6%、20日、周MA30、月MA10）都集中在脚本顶部常量区，可自行调整。

## 四、二次人工确认（初选通过 ≠ 买入）

清单只是第一道筛，下单前逐项确认：

- **形态**：日线是否处于 VCP 收缩末端或杯柄/平台突破点？还是已经连续大涨、离突破点太远（追高风险）？
- **回撤列**：距 52 周高点回撤越小越强（Minervini 标准是 ≤25% 最佳）。
- **基本面（CANSLIM 的 C/A/L）**：最新一季利润同比增速（C，欧奈尔建议 ≥25%）、年度增长（A）、是否行业龙头（L）。可在行情软件 F10 里查。
- **市场方向（M）**：大盘处于调整/下跌期时，即使个股形态好也应减仓或放弃——三本书一致认为 3/4 的股票跟随大盘。

## 五、风险控制铁律（书里最大的共同点）

- 单笔亏损上限 **7%-8%**（Minervini 自用更严：5%-10%，绝不放宽）
- 跌破买点或箱体下沿 → 无条件离场，不平摊、不补仓、不止损位下移
- 强势市里持股让利润奔跑；市场转弱信号（欧奈尔："高位放量滞涨、领涨股集体破位"）出现时先减仓

## 七、已知局限（诚实声明）

1. 新浪日K为**不复权**数据，个股除权除息日附近均线可能失真；腾讯兜底源为前复权，两源混用时同一只股票的结果可能有细微差异。
2. 涨停一字板无法买入，清单中此类股票仅作观察。
3. 未含基本面与行业信息，需二次人工确认（见第四节）。
4. 本系统为初选工具，不构成投资建议；所有买卖决策与盈亏由操作者本人承担。
