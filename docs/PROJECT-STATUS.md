## 三、当前可执行的定时动作

### 3.1 每日自动化流程 ✅ (已实现)

#### 🕖 19:00 - 强势股初选

**命令**:
```bash
tradebuddy.exe screen --date $(date +%Y-%m-%d)
```

**功能**:
- 扫描全市场 11722 只股票
- 筛选涨幅 ≥ 6%
- 筛选距52周高点 ≤ 25%
- 生成 Excel 报告

**输出**:
- `reports/screen_result_YYYYMMDD.xlsx`
- 数据库: `screen_results` 表

**耗时**: 3-6 分钟

---

#### 🕖 19:30 - 生命周期分析

**命令**:
```bash
tradebuddy.exe lifecycle --date $(date +%Y-%m-%d)
```

**功能**:
- 分析初选结果中的每只股票
- 计算波段持续时间、价格幅度、ATR标准化
- 市场排名和综合评分
- 评级分类 (A/B/C/D)

**输出**:
- `reports/lifecycle_result_YYYYMMDD.xlsx`
- 数据库: `lifecycle_metrics` 表

**耗时**: 1-3 分钟

---

#### 🕗 20:00 - 立花提示分析

**命令**:
```bash
tradebuddy.exe tachibana --date $(date +%Y-%m-%d)
```

**功能**:
- 基于生命周期结果生成交易信号
- 5种信号类型分类
- 价格区间和止损计算

**输出**:
- `reports/tachibana_result_YYYYMMDD.xlsx` (多Sheet)
- 数据库: `tachibana_signals` 表

**耗时**: 30-60 秒

---

#### 🔄 完整流程 (一键执行)

**命令**:
```bash
tradebuddy.exe run --date $(date +%Y-%m-%d)
```

**功能**:
- 自动串联上述三个步骤
- 一次性生成3份报告

**耗时**: 5-10 分钟

### 3.2 Windows 任务计划程序配置 ⏳ (待用户配置)

#### 方案 A: 使用批处理脚本

**创建文件**: `run_daily.bat`

```batch
@echo off
cd I:\tradebuddy
tradebuddy.exe run >> logs\daily_%date:~0,4%%date:~5,2%%date:~8,2%.log 2>&1
```

**任务计划程序设置**:
- 触发器: 每日 19:00
- 操作: 运行 `I:\tradebuddy\run_daily.bat`
- 条件: 仅当计算机处于交流电源时启动

---

#### 方案 B: 使用 PowerShell

**创建文件**: `run_daily.ps1`

```powershell
Set-Location "I:\tradebuddy"
$date = Get-Date -Format "yyyy-MM-dd"
.\tradebuddy.exe run --date $date
```

**任务计划程序设置**:
- 触发器: 每日 19:00
- 操作: `powershell.exe -File "I:\tradebuddy\run_daily.ps1"`
