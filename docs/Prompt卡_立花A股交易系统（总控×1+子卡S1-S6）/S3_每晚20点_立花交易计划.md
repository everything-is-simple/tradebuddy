# S3 · 每晚20:00 立花うねり取り交易计划

> 定时：每日20:00（`0 20 * * *` Asia/Shanghai）｜依赖：S1清单+S2生命周期｜下游：跟踪池跨日自维护

## 【任务】

立花うねり取り交易计划 · 每晚20:00自动执行（上游=S1清单+S2生命周期）。

## 【背景】

用立花取浪法对当日清单出具体交易计划。参数为1975-76账本159笔实证校验：

- 回档深度 `z=(MA20−现价)/ATR14`
- **回档带** z∈[0.8, 2.5]（押し目買回档买，账本5笔）
- **买入梯** = MA20 − 0.75/1.5/2.25 × ATR14（三档）
- **止损** = max(梯③−1×ATR, 60日线)
- **上沿** = MA20 + 2×ATR（第一止盈档）
- **乗せ区** z≤−2（强势延伸加码，账本28/32笔=主买入模式；2026-10-09新增观测列）

布网判定以S2生命周期阶段为可交易性过滤。脚本已实测，直接运行。

## 【资产】

- 脚本：`/home/z/my-project/scripts/tachibana_plan.py` + `tachibana_rules.py`
- 上游：`reports/stock_screen/A股备选清单_当日.xlsx`；`reports/lifecycle/生命周期分析_当日.xlsx`
- 产出：`reports/tachibana/立花交易计划_YYYY-MM-DD.xlsx`（四sheet：今晚交易计划/跟踪池/方法说明/数据校验）
- 跟踪池：`reports/tachibana/tracker.json`（跨日状态，脚本自维护）

## 【步骤】

1. 运行（超时8分钟）：`python3 /home/z/my-project/scripts/tachibana_plan.py`
2. 解析 stdout 末行 JSON：
   - `ok` 且 `count>0` → send_file 发送 Excel，标题"立花交易计划 {date}"，摘要≤8行：
     ① 布网N/观察M/排除K（排除主因点名，如"3·做头/4·下跌"）
     ② 回档带当前命中（突破日通常0=全部等回档）
     ③ 乗せ区命中（非空时点名"代码 名称 z"，固定提示："乗せ区=强势延伸加码区，账本实证为立花主买入模式(28/32笔)，但A股T+1追高受限、默认纪律仍为等回档布网，如参与只宜小仓试玉≤1/3预算"）
     ④ 跟踪池状态一行
     ⑤ 固定提示："买入梯为等回档挂单参考（非实时委托）；跌破止损参考无条件离场；参数加入时冻结不追改"
   - `ok` 且 `count=0` / `no_input` / `error` → 降级规则同S1（error重试1次，严禁编造）
3. 交付核对（硬规则）：pandas 重读 Excel——行数=上游清单数；布网/观察/排除与JSON一致；梯①②③价严格递减、止损<梯①（若止损≥梯②，判定原因须有"仅梯①可布"）；跟踪池行数一致；"乗せ区"列仅{✓乗せ区, 空}且与z≤−2一致；摘要数字当场读文件。

## 【口径】

- **布网** = 阶段∈{2·早期, 2·中期, 1→2·突破尝试}；**观察** = 2·晚期；**排除** = 1·筑底/3·做头/4·下跌/数据不足（宁可偏严）
- **仓位**：参考资金100万、单股风险预算1%（1万）、梯档配比40/30/30（梯①=试玉/梯②③=本玉，分层建仓）、股数向下取整100股、名义市值上限20万；止损线高于某梯则该梯作废（股数0）
- **跟踪池**：成交=当日最低价≤梯价；止损=当日最低价≤止损价（同日先成交后止损，保守计）；40自然日无成交过期；上限120条FIFO；加入后参数冻结
- **局限须声明**：日线判定不保证实际可成交（涨跌停/流动性/滑点未计）；T+1下分批节奏按梯价挂单实现；本计划为研究参考非投资建议

## 【禁忌】

不追突破（默认纪律）；不实时下单；不改跟踪池已冻结参数；不删跟踪池条目。

## 【异常】

上游缺席→no_input告知；K线失败个股→标"数据获取失败"进Excel；error→重试1次后如实报告。
