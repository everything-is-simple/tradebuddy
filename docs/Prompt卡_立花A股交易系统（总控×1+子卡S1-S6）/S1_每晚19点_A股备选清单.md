## 【任务】

A股备选股票筛选 · 每晚19:00自动执行。

## 【背景】

用户每日必做：筛出**当日涨幅>6% 且 当日最高价创20个交易日新高 且 周线与月线趋势均不在下跌**的A股清单，输出文档并标注关键信息。脚本已实测，不要重新实现，直接运行。

## 【资产】

- 脚本：`/home/z/my-project/scripts/stock_screen.py`（自动：交易日校验→拉全市场涨幅→三条件筛选→带自检Excel）
- 产出：`reports/stock_screen/A股备选清单_YYYY-MM-DD.xlsx`（历史按日留档）
- 待办便签：`reports/stock_screen/PENDING_NOTES.md` 存在则先读后清

## 【步骤】

1. 运行（超时10分钟）：`python3 /home/z/my-project/scripts/stock_screen.py`
2. 解析 stdout 末行 JSON：
   - `ok` 且 `qualified>0` → send_file 发送 JSON 的 file 指向 Excel，标题"A股备选股票清单 {date}"，摘要≤8行：入选家数 / 板块分布（主板·创业板·科创板）/ 涨幅前5（代码 名称 涨幅%）/ 量能与成交额观察 / 一行提示"清单不追高，买点梯为等回落挂单参考，完整交易计划见20:00文档"
   - `ok` 且 `qualified=0` → 不发文件，回复"今日无个股同时满足三条件"+剔除统计
   - `not_trading_day` → 一句话"今日非交易日，未生成清单"
   - `error` → 重试1次，仍失败如实报原因，严禁编造
3. 交付核对（硬规则）：用 pandas 重读 Excel——行数=qualified；三条件列全部达标；摘要数字当场读文件核实，严禁凭印象。

## 【口径】

- 范围：沪深A股（主板/创业板/科创板，不含北交所）
- 快照级剔除：ST/*ST/退市整理、上市<220个交易日、现价<5元、日成交额<1亿（含停牌）
- 条件A：当日涨幅>6%
- 条件B：当日最高价创20个交易日新高（前复权）
- 条件C：周线与月线趋势均不在下跌
- 三条件为硬筛选；本卡不做生命周期与立花参数（S2/S3的活）

## 【禁忌】

不引入额外条件；不追高推荐；不改脚本逻辑；不跨段补生命周期列。

## 【异常】

数据源失败→重试1次→仍失败告知并说明明晚自动再试；周/月线数据不足个股→剔除并摘要点名。
